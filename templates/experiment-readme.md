## 构建和运行

写清命令运行在哪个终端、哪个目录，按下面顺序填写项目的实际命令：

1. 仿真。
2. 编译固件和 RTL，生成位流。
3. 加载 SRAM。
4. 查看 LED、串口或其他输出。

涉及 Flash 时单独列出固化步骤，写明替换后的上电行为。

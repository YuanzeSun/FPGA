# 自写 RISC-V CPU 算法实验台

Tang Nano 9K 上的 SimpleRV32I CPU 执行 C 算法。电脑只负责发送输入和显示串口结果，无需 HDMI。

## 开始

双击本目录 `Algorithms.cmd`。启动器核对源码、位流和设备，再加载 SRAM 并打开串口控制台。输入命令后按回车；`exit` 退出并释放串口。已有串口窗口需先关闭。

默认 COM6，115200、8N1。换端口时可运行 `powershell.exe -NoProfile -File scripts/start.ps1 -PortName COM7`。

只写 SRAM，断电后需要重新加载；Flash 中的单灯程序不变。若本实验已在板上运行，可直接运行 `powershell.exe -NoProfile -File scripts/console.ps1`，不必重新加载。

## 命令

| 输入示例 | 结果和含义 |
| --- | --- |
| `sort 9 -2 5 1` | 排序为 -2、1、5、9；分别测量插入排序和冒泡排序 |
| `find 5 1 3 5 7` | 在升序数组中找 5，返回下标 2；不存在返回 -1 |
| `maxsub -2 1 -3 4 -1 2 1 -5 4` | 最大连续子数组和为 6，对应下标 3～6，即 4、-1、2、1 |
| `gcd 48 18` | 二进制最大公约数算法，返回 6 |
| `info` | CPU、指令集、频率、存储容量 |
| `help` | 命令提示 |
| `ping` | 返回 PONG |
| `demo` | 电脑控制台依次发送以上四个算法示例 |

每个整数范围为 -1,000,000～1,000,000。数组最多 16 个数；find 的第一个数是目标，后面才是数组。gcd 的两个数必须非负，本实验约定 gcd(0,0)=0。下标从 0 开始，maxsub 的两端均包含在结果中；二分查找遇到重复值时可以返回任意一个匹配位置。

串口固件按行接收，回传 READY 表示本条命令处理完毕。配套控制台会控制发送速度，避免板上单字节 UART 接收器来不及取走数据。不要在处理上一条命令期间连续粘贴多行。

## 怎么理解性能数据

cycles 是硬件时钟计数器差值，instructions 是核心已完成指令计数器差值。CPU 为 13.5 MHz，微秒数约等于 cycles / 13.5。

计时范围包含算法调用和少量计数器读取开销，不含输入解析、数组准备和串口打印。排序函数还包含比较次数、数组写入次数的统计代码，因此这些是带统计的实现结果。moves 只计算数组元素写入，不计算局部临时变量的赋值。冒泡排序带有“本轮没有交换则提前结束”的优化。

不要仅按一次小样本判断算法复杂度：可比较升序、逆序、重复值和不同长度。当前上限为 16，用于学习和观察 CPU 指令行为。

## 代码从哪里看

- `firmware/algorithms.c`：四种题型的纯 C 算法，不依赖硬件。
- `firmware/main.c`：输入解析、串口打印、读取计数器、调用算法。
- `src/simple_soc.v`：存储器和串口、GPIO、计数器的地址映射。
- `src/rv32_core.v`、`rv32_decode.v`、`rv32_regfile.v`、`rv32_alu.v`：与原 SimpleRV32I 工程逐字一致的 CPU 核心。

片上程序 ROM 扩为 16 KiB（当前固件 3400 字节），数据与栈 RAM 仍为 1 KiB。RAM 从原实验的 0x1000 移到 0x4000，链接脚本同步调整。没有添加 M/C 扩展或中断，仍为基础 RV32I。

## 地址与灯光

| 地址 | 含义 |
| --- | --- |
| 0x00000000～0x00003FFF | 16 KiB 程序 ROM |
| 0x00004000～0x000043FF | 1 KiB 数据/栈 RAM |
| 0x40000000 | 六位 GPIO |
| 0x40000004 / 0x40000008 | UART 发送 / 接收 |
| 0x4000000C | UART 状态 |
| 0x40000010 | 32 位时钟计数器 |
| 0x40000014 | CPU 异常原因 |
| 0x40000018 | 新增映射：CPU 已完成指令数，只读 |

第一颗灯：启动完成。第二颗：执行算法期间。第三颗：最近一次算法命令成功。第六颗：输入错误。灯显示最近状态，不是流水灯；短算法的执行灯可能来不及肉眼观察。全六灯常亮表示 CPU 异常停机。

## 构建与验证

使用已有 WSL 和工具，不需要新增软件：

```powershell
powershell.exe -NoProfile -File tools/build.ps1 -Project rv32i-algorithms
```

构建包含原有 26 组 CPU 指令对照测试、4204 项算法参考答案比对和未定义行为检查、实际 CPU RTL 运行固件的 UART 仿真，以及综合、布局布线、时序和位流 CRC 检查。CPU RTL 仿真覆盖四类算法及错误输入。

加载：`python scripts/program_sram.py`。板上验收：`powershell.exe -NoProfile -File scripts/test_serial.ps1`。硬件测试向板上发送 32 条命令，并检查返回值、非零性能计数、错误处理和出错后恢复。

已验收结果见 `reports/validation.json`；算法硬件输入见 `reports/algorithm-cases.json`；本机构建结果位于 `build/`。不应把电脑端的参考答案比对误当成板上执行；两类结果分开记录。

统一构建命令在仓库根目录执行；直接运行项目脚本时应先进入本项目目录。环境见[环境说明](../../docs/environment.md)。

# CPU、显存与串口

官方PicoRV32核心执行RV32IMC固件，CPU25.2MHz。启用32整数寄存器、双读口、64位计数器、桶形移位、压缩指令、迭代乘法、除法、两周期ALU/比较及非法/未对齐检测；本项目不启用IRQ、外接PCPI和trace。

| 地址 | 外设或存储 |
| --- | --- |
| 0x00000000～0x00003FFF | 16KiB程序ROM |
| 0x00010000～0x00011FFF | 8KiB数据与栈RAM |
| 0x02000000 / 0x02000004 | UART分频 / 收发数据 |
| 0x02000010 | 60Hz逻辑计时 |
| 0x02000014 | 请求翻页；bit0待确认，bit1前台页 |
| 0x02000018 | UART FIFO溢出 |
| 0x02000020～0x02000034 | 软件状态 |
| 0x03000000～0x03001FFF | 后台字符显存 |

显存每4字节寻址一个16位单元：bit7:0字形，bit11:8前景色，bit15:12背景色。画布40×30字符，每字16×16像素，两个2048单元的缓冲页。

CPU画完后台页后请求翻页，视频模块在帧边界切换，完成旧页最后一次RAM读取后返回确认；CPU收到确认后才改写该页。高清模块的CPU写时钟与像素读时钟独立。

UART输入FIFO为16字节。按键字节为0x80加按键掩码：左1、右2、上4、下8、发射16、旋转32；0x80释放按键。文本命令1～4切换，m手动，a自动，p暂停，r重开，?查询。控制窗口每80ms刷新按住的键。

RISC状态行由C固件生成：G游戏号、F逻辑帧计数、S分数/字数、X/Y坐标、T状态、A自动、P暂停、C收令计数、K最后字节，数值使用十六进制。
